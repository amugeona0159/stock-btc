맞췄다. 2026-08-30 측정, 시장마다 origin 60개, 8 origin 마다 재학습.
설정은 `window 48 · folds 3 · bars 3000 · 사라 3 · 사지 말 것 3` 한 벌이다.

**뒤 20%(12판)가 holdout 이다.** 추천 규칙을 만질 때 그 구간은 안 본다. 성적은
holdout 쪽을 읽는다 — 튜닝에 쓴 구간에서 잰 값은 자기 답을 보고 만든 성적이다.

`차이` = 추천 셋의 평균 − **후보 전체 평균**. 0 과 견주면 고르는 실력이 아니라
시장을 재게 된다.

## 읽는 법

### 1. 고르는 실력이 안 보인다

**holdout 열다섯 칸 중 열둘이 음수다.** 튜닝 구간도 −0.89 ~ +0.09%p 로 0 언저리다.
"기대 수익률 상위 셋"이 후보 전체를 산 것보다 나았다는 증거가 없다.

놀랄 일은 아니다. `docs/STUDY.md` 가 방향 적중을 27,664판에서 **55.0%** 로 재 뒀고,
횡단면 방향 스프레드는 하루 +0.03%p · 사흘 +0.65%p 였다. 그 크기는 12판으로는
잡히지 않는다 — 같은 구간의 시장 움직임(코인 3일 holdout 에서 후보 평균이 +5.88%)이
그보다 자릿수로 크다.

**그래서 이 표가 말하는 것은 "추천이 나쁘다"보다 "이 표본으로는 아무 말도 못 한다"에
가깝다.** 다만 **좋다는 증거가 없다**는 것도 사실이고, 화면은 그렇게 읽히게 써야 한다.

### 2. 국내주식만 양수다 — 그런데 믿을 수 없다

`toss_kr` 이 holdout 세 칸 모두 양수다(+0.57 / +0.88 / +1.27%p, 이긴 비율 67~75%).
유일하게 좋아 보이는 자리라 가장 조심해야 한다:

- **튜닝 구간에서는 세 칸 다 음수다**(−0.05 / −0.22 / −0.43%p). 같은 규칙이 48판에서
  지고 12판에서 이겼다. 부호가 뒤집혔다는 건 표본이 갈랐다는 뜻이지 실력이 아니다.
- 그 구간의 밴드 적중이 **90 / 93 / 97.5%** 다(목표 80%). 밴드가 넘치게 넓다는 건
  **그 구간이 평소보다 조용했다**는 뜻이고, 조용한 구간에서 상위 셋이 앞선 것은
  변동성 뭉침의 부산물일 수 있다.
- 12판이다. +1.27%p 의 신뢰구간은 0 을 한참 넘나든다.

**"국내주식은 된다"로 읽지 말 것.** 다음 측정에서 뒤집히면 그건 새로운 소식이
아니라 원래 그 정도 잡음이었다는 뜻이다.

### 3. 미국주식은 두 소스가 같은 답을 냈다

`toss_us` 와 `yahoo` 는 같은 열 종목을 서로 다른 데서 받아 온다. 그런데 holdout
차이가 −0.15/−0.31/−0.43 과 −0.20/−0.36/−0.51 로 거의 겹친다.

**측정 자체는 재현된다**는 뜻이다. 숫자가 데이터 출처의 우연이 아니라는 확인이라,
"고르는 실력이 안 보인다"는 결론이 그만큼 단단해진다.

### 4. 밴드가 코인 최근 구간에서 무너졌다 — 여기가 진짜 신호다

목표는 80%다. 코인은 튜닝 구간에서 84~87% 로 오히려 넉넉했는데, **holdout 에서
52~72% 로 떨어졌다.** 지평이 길수록 심하다(1일 70~72% → 3일 52~59%).
주식은 반대다 — 미국은 78~79% → 87~92%, 국내는 84~86% → 90~98%.

즉 **코인에서만, 최근 구간에서만** 무너졌다. 그 구간(2026-08-14 ~ 08-25)은 후보
평균이 사흘에 +5.88% 였던 급등 구간이다. 컨포멀 보정은 검증 구간의 벗어난 정도를
모아 넓히는 것이라, **보정한 구간보다 뒤가 더 시끄러우면 밴드가 좁게 남는다.**

**이건 고칠 수 있는 자리다.** 다만 고치기 전에:

- 12판이다. 52.5% 는 95% 신뢰구간으로 대략 27~77% 다. 한 구간의 변동성 급등일 수 있다.
- **밴드를 좁히지 말 것.** CLAUDE.md 의 규칙 그대로 — 목표에 못 미치면 넓히되
  좁히지는 않는다. 지금 국내주식이 97.5% 라 좁힐 유혹이 생기는데, 그건 사례가 적을 때
  우연히 높게 나온 커버리지로 밴드를 조이는 짓이다.
- 다시 재려면 origin 을 더 잡아 급등 구간이 holdout 안에서 여러 번 갈리게 해야 한다.

### 5. 하지 말아야 할 것

- **이 표를 보고 추천 규칙을 고치고 다시 재서 좋아진 숫자를 쓰는 것.** 그렇게 하면
  holdout 이 튜닝 구간이 된다. 규칙을 만졌으면 origin 을 뒤로 더 밀어 새 holdout 을
  만들거나, 실전 채점(`scores.jsonl`)이 쌓이기를 기다린다.
- **승격에 쓰는 것.** 모델 승격은 워크포워드(`scripts/daily.py`)로만 한다.
  as-of 를 승격 기준에 넣으면 그것도 학습 구간이 된다.
- **`avoidPct` 를 성적으로 읽는 것.** 사지 말 것은 "그 묶음 안에서 꼴찌"라는 뜻이지
  공매도 신호가 아니다.
- **묶음끼리 견주는 것.** 코인 holdout 의 +5.08% 와 국내주식의 +1.58% 는 그 구간
  시장이 그만큼 다르게 움직였다는 말이지 추천의 우열이 아니다.

## 다시 재는 법

```bash
.venv/Scripts/python scripts/backfill.py --provider binance --origins 60
.venv/Scripts/python scripts/backfill.py --summary
```

설정(`window`·`folds`·`bars`·`사라/사지 말 것` 수)을 바꿨으면 `--restale` 로 옛 설정
줄을 버리고 다시 돌린다. `--summary` 가 설정이 섞이면 경고한다. 화면
(`api/recommend.py`)은 **가장 최근 설정으로 잰 줄만** 세고 나머지는 `staleRows` 로
알린다 — 옛 모델 성적과 새 모델 성적이 한 숫자에 섞이면 그게 정확히 못 믿을 숫자다.
